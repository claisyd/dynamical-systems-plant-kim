def show_table(rows, cols=None, float_fmt="{:.6g}"):
    if not rows:
        print("(empty)")
        return
    cols = cols or list(rows[0].keys())
    # header
    widths = []
    str_rows = []
    for c in cols:
        vals = []
        for r in rows:
            v = r.get(c, "")
            if isinstance(v, float) or (isinstance(v, str) and v not in ("",) and _is_float(v)):
                try:
                    vals.append(float_fmt.format(float(v)))
                except Exception:
                    vals.append(str(v))
            else:
                vals.append(str(v))
        widths.append(max(len(c), max(len(x) for x in vals)))
        str_rows.append(vals)
    # transpose back
    grid = list(zip(*str_rows))
    hdr = " | ".join(c.ljust(widths[i]) for i, c in enumerate(cols))
    sep = "-+-".join("-" * widths[i] for i in range(len(cols)))
    print(hdr)
    print(sep)
    for row in grid:
        print(" | ".join(row[i].ljust(widths[i]) for i in range(len(cols))))

def _is_float(s):
    try:
        float(s)
        return True
    except Exception:
        return False

6. Hopf period prediction¶

At $H_{\mathrm{bio}}$, $$ T_{\mathrm{lin}} = \frac{2\pi}{\omega_H},\qquad \omega_H = |\mathrm{Im}\,\lambda_H|. $$ AUTO LC-C periods on the Hopf bubble are compared as cycle amplitude $V_{\max}-V_{\min}\to 0$. Time unit: milliseconds.

7. Hopf transversality¶

Centred finite differences of $\mathrm{d}\,\mathrm{Re}(\lambda_{\mathrm{crit}})/\mathrm{d}\alpha_P$ at several step sizes $h$, plus the semi-analytical formula $$ \frac{\mathrm{d}\lambda}{\mathrm{d}\alpha_P} = w^{H} \frac{\mathrm{d}J}{\mathrm{d}\alpha_P} v $$ with $w^{H}v=1$ and equilibrium dependence through $\mathrm{d}x^{*}/\mathrm{d}\alpha_P=-J^{-1}F_{\alpha_P}$.

8. Saddle-node nondegeneracy¶

At $LP_{\mathrm{bio}}$, left/right nullvectors satisfy $Jq=0$, $p^{\mathsf T}J=0$, $p^{\mathsf T}q=1$. Coefficients $$ a = p^{\mathsf T} F_{\alpha_I},\qquad b = \tfrac12 p^{\mathsf T} D_x^{2}F[q,q] $$ are computed from the symbolic Hessian action. Nearby equilibria satisfy $u=\pm\sqrt{-(a/b)\,\Delta\alpha_I}$ in the reduced coordinate, so the voltage deviation is $$ V-V_{LP}\approx q_V\,u=\pm q_V\sqrt{-(a/b)\,\Delta\alpha_I}. $$
